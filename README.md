**State (2026-11-17 KST): repository bootstrap only. NO product implementation, E2E verification, cloud deployment, GitHub permission change, or release approval.**

Canonical architecture, security gates, requirements, implementation queue, and handoff are prepared on a dedicated design branch; `main` is kept as the minimal stable bootstrap. **Security:** This repository is public. Never commit credentials, customer code/data, private plans, source snapshots, `.env`, model weights, personal prompts, local SQLite databases, unredacted logs, backups or runtime evidence. Existing GitHub permissions and hosting settings remain unchanged.
